# Empirica

A virtual lab: walk a 3D lab building, step into 2D stations, run experiments across chemistry, biology, physics, astrophysics and more. Deterministic simulations, explanations at three levels.

    npm install
    npm run dev     # dev server
    npm test        # unit tests
    npm run build   # typecheck + production build
    npm run deploy  # build, rsync to https://empirica.vawagners.cloud/, check it serves this build

Hosted by millwright; every push to `main` deploys. See `DEPLOYMENT.md`.

Roadmap: `.scratchpad/roadmap/empirica-v1/map.md`
